# StyleFix v2.0 Development Baseline

The `v2.0-dev` branch starts from the certified StyleFix v1.0.8 audit release.

The inherited runtime remains v1.0.8 until v2.0 implementation begins. This preserves the certified baseline as the starting state rather than changing version identifiers before behavior changes.

The v2.0 major-version boundary is reserved for guarded remediation and other behavior that changes StyleFix from evidence collection into an evidence-driven action tool. The v1.0.8 audit, DOM-contract, authorization, canary, and progress-window behavior form the regression baseline for that work.
